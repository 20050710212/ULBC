Title:    Thoughts on the Figure of Merrit for Qualification/Selection Tests

## 1. Introduction

<a id="P006"></a>

Recently, proposals have been discussed to consider complexity metrics for the figure of merit (FoM).

<a id="P007"></a>

In previous standardization efforts such as EVS or IVAS, the figure of merit typically consisted of two components:

<a id="P008"></a>

An elimination rule which has eliminated candidates which have not fulfilled the mandatory design constraints

<a id="P009"></a>

A selection rule which was based on perceptual performance

<a id="P010"></a>

There are however thoughts to combine the perceptual performance with a complexity based score for the selection rule. The source sees significant disadvantages using such an approach, which will be discussed below.

<a id="P011"></a>

## 2. Discussion

<a id="P012"></a>

In the past, the design constraints have defined upper limits for a maximum computational complexity and memory demand, which had to be matched by all proponents. These constraints are typically defined based on availability of hardware and the estimated demand needed to match the performance requirements. Adding a complexity based component to the FoM removes this constraint – at least partially. Instead, candidates might significantly exceed these constraints in certain dimensions, making them unsuitable for certain (planned for) hardware configurations.

<a id="P013"></a>

In addition, it’s unclear to the source how a weighting between perceptual quality and complexity based figures will be defined. The source sees many options to find such weighting factors. In addition, such potential factors might be very specific to certain devices or models. The source is afraid that this might lead to lengthy discussions and an overall unfair and unexplainable FoM.

<a id="P014"></a>

## 3. Conclusion

<a id="P015"></a>

It is thus proposed to build the FoM solely based on the following two components:

<a id="P016"></a>

An elimination rule which eliminates candidates which do not fulfill the mandatory design constraints

<a id="P017"></a>

A selection rule which is solely based on perceptual performance
