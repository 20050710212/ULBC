Title: · On Alternatives for Selection without a Qualification Phase

## 1. Introduction

<a id="P006"></a>

The current work plan for the ULBC-MED selection process includes a qualification phase intended to narrow down the 20 registered candidates to a limited number of e.g. 5 candidates prior to the selection phase [1]. This contribution argues that a full qualification phase is not the most efficient approach, taking into account resource requirements, schedule constraints, and expected outcomes.  Two alternatives are proposed: Option 1 proceeding directly to selection without qualification, or Option 2 replacing qualification with a lightweight pre-screening step.

<a id="P008"></a>

## 2. Background

<a id="P009"></a>

Current facts:

<a id="P010"></a>

## 20 candidates indicated interest

<a id="P011"></a>

Minimum cost per test according to the labs: 18kEur

<a id="P012"></a>

All operating points require separate testing

<a id="P013"></a>

Qualification decision scheduled: SA4#139 (February 2027)

<a id="P014"></a>

Selection submission planned: March 2027

<a id="P015"></a>

The current timeline is already constrained by the complexity of the selection process and coordination requirements among multiple test laboratories and proponents. This creates significant schedule risk if the qualification phase encounters any delays.

<a id="P017"></a>

## 3. Rationale for Avoiding a Full Qualification Phase

<a id="P018"></a>

## 3.1 Cost Considerations

<a id="P019"></a>

With 20 candidates and a minimum testing cost of 18kEur per test, while taking into account the analysis in [2], the total expenditure for a complete qualification phase would be substantial. This represents a considerable investment prior to the selection phase.

<a id="P020"></a>

## 3.2 Schedule Risk and Timeline Constraints

<a id="P021"></a>

The current work plan is already constrained by multiple dependencies. Introducing a full qualification phase adds a sequential layer, increasing overall timeline and reducing flexibility.

<a id="P022"></a>

Impact:

<a id="P023"></a>

Any qualification phase slippage directly impacts selection timeline

<a id="P024"></a>

Reduces flexibility to accommodate unforeseen challenges

<a id="P026"></a>

## 3.3 Standardization Overhead and Resource Allocation

<a id="P027"></a>

A full qualification phase requires significant additional standardization effort:

<a id="P028"></a>

Separate qualification test plans and processing plans

<a id="P029"></a>

Additional coordination for qualification decision

<a id="P030"></a>

Diverts resources from finalizing Design Constraints and Permanent Requirements

<a id="P032"></a>

## 4. Proposed Option 1: Direct to Selection (No Qualification Phase)

<a id="P033"></a>

## 4.1 Approach

<a id="P034"></a>

All 20 expected candidates would be eligible for inclusion in the selection phase. This simplifies the overall selection process by consolidating all candidate evaluation into a single, well-defined phase.

<a id="P035"></a>

## 4.2 Advantages

<a id="P036"></a>

Extended development time: Achieve potentially better quality candidates

<a id="P037"></a>

Minimized testing cost: Eliminates an entire layer of testing expense; more efficient budget allocation

<a id="P038"></a>

Equitable cost distribution: All candidates treated equally with identical testing costs and evaluation criteria

<a id="P039"></a>

Reduced standardization effort: Avoids need for separate qualification test plans and processing plans

<a id="P040"></a>

Schedule relaxation: Eliminates a sequential step, providing flexibility and reducing schedule risk

<a id="P041"></a>

## 4.3 Potential Concerns

<a id="P042"></a>

Candidate pool size: With 20 candidates, statistical clarity of results may be reduced; similar-performing candidates could complicate final decision

<a id="P043"></a>

Reduced testing range: With 20 candidates per test, fewer operating points per experiment can be evaluated. In case the number of experiments stays constant, fewer operating points can be evaluated during selection tests.

<a id="P044"></a>

Risk of selection re-run: Inconclusive results might necessitate re-run, negating some savings achieved by eliminating qualification

<a id="P045"></a>

## 5. Proposed Option 2: Lightweight Pre-Screening Phase

<a id="P046"></a>

## 5.1 Proposed Approach

<a id="P047"></a>

Option 2 proposes replacing the full qualification phase with a lightweight pre-screening step designed to narrow the candidate pool while minimizing added cost and complexity. The approach would:

<a id="P048"></a>

Employ clean speech samples and clean channel conditions

<a id="P049"></a>

Test both bitrates at wideband (WB) operation

<a id="P050"></a>

Use a discriminative Figure of Merit (FoM): e.g. counting points for passing NWT against AMR-WB from 8.85 kbps up to EVS 13.2 kbps – as discussed in [3] and proposed in [4]

<a id="P051"></a>

Require all candidates to meet objective performance criteria

<a id="P052"></a>

Advance top 10 candidates to full selection phase

<a id="P053"></a>

This middle-ground approach reduces the candidate pool through a streamlined process while maintaining significantly lower cost and complexity compared to full qualification.

<a id="P055"></a>

## 5.2 Advantages

<a id="P056"></a>

Removes candidate pool uncertainty: Enables precise planning

<a id="P057"></a>

Doubles selection phase testing bandwidth: Reducing pool from 20 to 10 doubles available testing resources, allowing more thorough evaluation, including testing at additional operating points

<a id="P058"></a>

Filters non-competitive candidates: Removes clearly non-competitive candidates; reduces noise in final selection results

<a id="P059"></a>

Significantly lower cost: Requires very few test conditions, simpler evaluation criteria, and less coordination than full qualification

<a id="P060"></a>

Maintains fairness: All candidates evaluated under identical conditions and against same objective metrics

<a id="P061"></a>

## 5.3 Potential Concerns

<a id="P062"></a>

Additional testing effort: Requires more testing time and effort than Option 1, though substantially less than full qualification

<a id="P063"></a>

Delayed start: Design of pre-screening criteria could delay process

<a id="P064"></a>

## 7. Conclusion

<a id="P065"></a>

It is proposed to abandon the current full qualification phase plan and it is requested that the group discusses options 1 and 2 and decides which approach best aligns with the Audio SWG’s priorities and resource constraints.
