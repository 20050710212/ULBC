# Step 3F：降噪、非语音鲁棒性与输出增益

> 范围：3.17 Noise suppression and robustness to non-speech input、3.18 Output gain tolerance。连接 ULBC-4 的原则、ULBC-3 的门槛和 ULBC-7 的工具。184 两条均保留未决标记，不能把示例容差当作已通过要求。

## 2. 3.17：噪声保存与抗干扰能力并非同一指标

噪声抑制影响接收者听到的背景信息；非语音鲁棒性还涉及警笛、鸟鸣、风声、音乐等输入下的语音可懂度与异常输出行为。

[121，Dolby](../step02_performance_requirements/S4aA260121_source.md)提出扩展噪声类别，同时限制背景噪声过度衰减。动机是让真实场景的声音保留与语音质量一起评估，而不是仅比较安静化后的听感分数。

[141 的 Orange 附件](S4aA260141_attachment_source.md#T019)进一步提议 noisy speech 不被过度衰减、限制在 ULBC-3/工具在 ULBC-7 定义，并提出可命令行开启的降噪默认关闭。184 没有把这些全部写成无括号约束，不能声称“当前已明确禁止一切降噪”。

### 2.1 删掉独立条目会不会丢掉要求

若该条最终转入 gain/ULBC-3，需要检查覆盖范围：输出能量限制可约束过度衰减，却不能单独证明模型对未见噪声、纯音乐或瞬态警报输入稳定。

分析上建议分别追踪语音质量、背景能量、非语音输入行为、DTX/CNG 背景连续性，避免因为章节合并而漏掉某一能力。当前文本没有这些维度的完整阈值。

## 3. 3.18：增益检查要分清目的

[168，VoiceAge](../step02_performance_requirements/S4aA260168_source.md)讨论五类输出能量问题：

| 方面 | 168 的提案路线 |
|---|---|
| 最大输出放大 | 用 ULBC-7 客观工具检查 |
| 最低 WB 能力/频带衰减 | 提出以适当 P.800 DCR 主观测试隐含验证 |
| 人工带宽扩展的高频能量 | 用客观工具检查 |
| inactive clean speech 过度衰减 | 用客观工具检查 |
| inactive noisy speech 过度衰减 | 用客观工具检查 |

168 在 R4 的分配状态为 a，但不能由此认为 184 中所有容差和工具实现已自动定案。尤其最低 WB 检查：该贡献没有要求所有能量方面一概使用客观工具。

### 3.1 评分公平性与实际输出行为

168 区分两个目的：防止人为放大 active speech、压低 inactive noise 来提高听测分数，以及保证实际部署输出的合理电平。测试中把合成输出重新缩放，可能有助公平比较，但会掩盖 codec 原始增益行为。

因此应保留原始输出供合规检查，再按明确 processing plan 生成用于听测的版本；不能只留归一化后文件。这是本分析的流程建议，具体缩放法仍需按 ULBC-7 决定。168 提到 BS.1770/P.56，但没有因此冻结所有场景的选择。

### 3.2 全频带、子频带和时间区间

整体能量接近输入，仍可能隐藏某些频带被削弱、另一些频带被增强。active 区间与 inactive 区间的行为也可能不同；全文件均值不能替代两者分别检查。

建议测量说明至少定义：时间对齐、active/inactive mask、频带边界、低能量帧排除、DTX on/off、统计汇总以及零能量处理。否则相同 codec 可能因工具链不同得到不同增益数字。

用于理解能量差的常见形式是 `10 log10(Eout / Ein)`，前提是同一对齐区间、同一频带且能量有效。这不是 184 已指定的唯一算法，也不能把瞬时点值直接替代最终统计门槛。

## 4. 与 Step 2 的衰减要求对齐

[180 当前性能基线](../step02_performance_requirements/S4aA260180_source.md)和[Step 2 分析](../step02_performance_requirements/Step02_ULBC3_performance_analysis.md)仍保留以下候选数字：

| 场景 | DTX off 最大背景衰减 | DTX on 最大背景衰减 |
|---|---:|---:|
| inactive clean speech | [6] dB | [12] dB |
| inactive noisy speech | [4] dB | [12] dB |

这些是方括号门槛；121 提案解释了同方向数值，不代表 180 已解除全部括号。它们约束背景衰减，不能与 184 的一般 [0.5 dB] gain 候选混成一个标准。

DTX-on 时接收背景可能来自 CNG，不是简单的输入噪声逐样本重建。测量必须先定义哪些段可比较、SID 更新和对齐怎样处理，才能解释衰减结果。D 的 SID 间隔也会影响背景跟踪质量。

## 5. WB、SWB 与人工高频的连接

A 已明确 WB 必须、SWB 可选。168 还指出 WB 是到 7 kHz 还是 8 kHz 需要澄清。

32 kHz 输出并不能证明其高频内容忠实；高频能量非零也不能单独证明 SWB 质量。人工带宽扩展需要区分合理重建与不适当增强，不能仅以“输出比输入高频能量大”就判失败，尤其输入某频带几乎无能量时比例会不稳定。最终应按 ULBC-7 的条件及参考定义验证。

## 6. 三份 Pdoc 的分工应怎样闭合

| 文件 | 应明确的内容 |
|---|---|
| ULBC-4 | 是否设独立设计约束、禁止/允许行为边界 |
| ULBC-3 | 适用场景、阈值、DTX 模式、通过判据 |
| ULBC-7 | 对齐、频带、mask、排除规则、工具和缩放流程 |
| ULBC-5/8 | 实际评价条件、结果报告与合规记录 |

这是职责梳理，未声称各文件已填完。当前应核对独立降噪条目去留、gain 容差、WB 边界、能量工具以及与 CNG 的一致性。

## 7. 本组结论

当前不能把“禁止降噪”或“所有输出统一 ±0.5 dB”写成已定结论。应把背景保持、输出放大、频带能力和非语音鲁棒性分别追踪，再将主干原则、性能门槛与测量工具连接起来。
